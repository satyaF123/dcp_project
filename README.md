# column descriptions of my csv file

|Item name|This column is for the title of the produce and takes string values|
|---------|-------------------------------------------------------------------|
|Category|This column is for type of product , it takes string values|
|Date Purchased|The date the Item was purchased , Takes DATE format value|
|Amount|This column is for the price of the quantity of the item that I bought , takes in Currency values in Euro|
|Needed|This column is a binary yes/no column for whether the item is a necessity or not|
|Quantity|This column is for the quantity of the item that was bought it takes in floating values|
|Unit|This column is to help understand the quantity column , it is the unit of the quantity purchased and takes string values|
|Unit Price|This column is for Calculating the unit price using amount/quantity and takes in floating values|
|Store|The store the product was purchased from , takes in string values|
|Discount|Whether the product purchased was discounted or not , takes in binary yes no values|
